## 1. Архитектура и стек технологий

- **Язык и фреймворк**: C++20 + Qt 6 (Qt Quick / QML).
- **Графический бэкенд**: Qt Quick Scene Graph с аппаратным ускорением (OpenGL, Vulkan, Direct3D, Metal) через Qt RHI (Rendering Hardware Interface).
- **Core-бэкенд (`spotify-core`)**: Высокопроизводительное ядро на **Rust**, инкапсулирующее библиотеку `librespot` и Spotify Web API. Общается с C++ через C ABI (`swiftify_core.h`).
- **Сетевой стек и корутины**: `QCoro` (асинхронность на базе C++20 корутин).
- **Безопасное хранение секретов**: `QtKeychain` (GNOME Keyring, KWallet, Windows Credential Manager, Apple Keychain).
- **Лицензия**: GNU GPLv3+.

## 2. Аудио-движок и воспроизведение

### Двойной бэкенд воспроизведения
1. **Встроенный `librespot` (Spotify Connect Core)**:
   - Декодирование Ogg Vorbis (битрейт 96, 160, 320 kbps).
   - Прямой кэш аудиопотока и учет токенов авторизации.
   - Поддержка аккаунтов со Spotify Premium.
2. **Spotify Soloist (Fallback для новых аккаунтов)**:
   - Обход ошибки `audio key 0 1` для аккаунтов, где Spotify ограничивает ключи расшифровки.
   - Swiftify автоматически поднимает процесс `soloist` и создает виртуальный аудио-синк (на Linux через PipeWire/PulseAudio `Swiftify (Soloist)`).
   - Поток захватывается обратно в DSP-пайплайн Swiftify, сохраняя работоспособность эквалайзера и спектральных анализаторов.

### Возможности воспроизведения
- **Gapless Playback**: Бесшовный переход между треками без пауз и щелчков (идеально для концептуальных альбомов и живых записей).
- **Crossfade**: Настраиваемое плавное затухание/нарастание громкости при переключении песен (0–12 секунд).
- **ReplayGain / Volume Normalization**: Автоматическое выравнивание громкости треков до единого стандартизированного уровня (-14 LUFS).
- **Preamp Gain**: Дополнительное программное усиление входного сигнала (+/- dB).
- **Управление очередью (Playback Queue)**: Очередь следующего трека, динамическая перестановка треков, сохранение контекста источника (плейлист/альбом/артист).
- **Режимы повтора и перемешивания**: Shuffle (случайный порядок), Repeat Off, Repeat Context, Repeat One.

## 3. DSP, эквалайзер и шейпинг звука

Все преобразования выполняются на лету над PCM-буфером в модуле `AudioShaping`:
- **10-полосный параметрический эквалайзер**:
  - Точная настройка частот: 31Hz, 62Hz, 125Hz, 250Hz, 500Hz, 1kHz, 2kHz, 4kHz, 8kHz, 16kHz.
  - Регулировка гейна от -12 dB до +12 dB на полосу.
  - Визуализация кривой АЧХ (интерактивный виджет `EqualizerCurve.qml`).
- **Pitch Shifting (Изменение тональности)**:
  - Сдвиг высоты тона в полутонах без изменения скорости воспроизведения (интеграция Rubber Band Library / SoundTouch).
- **Tempo Shaping (Изменение темпа)**:
  - Плавное ускорение или замедление трека (от 0.5x до 2.0x) с сохранением оригинальной высоты звука.

## 4. Интерфейс, шейдеры и визуализация (Eyecandy)

Дизайн приложения опирается на принципы **Material 3 Expressive** (глубокие формы, динамические скругления, адаптивная палитра).

### Кастомные GLSL-шейдеры (`shaders/`):
- **`liquid_backdrop.frag`**: Плавный анимированный фон с эффектом перетекающей жидкости, подстраивающий цвета под обложку текущего альбома.
- **`spectrum_bars.frag` & `spectrum_halo.frag`**:
  - 64/128-полосный анализатор спектра в реальном времени.
  - Режимы отображения: классические столбики, круговой ореол (halo вокруг обложки), мягкое волновое сглаживание.
- **`wavy_line.frag` & `wavy_progress.frag`**:
  - Интерактивная «живая» полоса прогресса воспроизведения и слайдер громкости, колеблющиеся в такт музыке.
- **`backdrop_blur.frag`**: Высокопроизводительное двухпроходное размытие по Гауссу для подложек панелей.
- **`soft_shadow.frag` & `material_shape.frag`**: Мягкие тени и контурные геометрические формы (Squircle, органические закругления) без деградации FPS.

### Динамическая тема (Color Extraction):
- Цвета панелей, кнопок и шрифтов автоматически извлекаются из обложки текущего трека через алгоритмы `ArtworkPalette` (Dominant, Vibrant, Muted, Accent).
- Поддержка темного, светлого и глубокого контрастного режимов.

## 5. Экраны, навигация и медиатека

- **Главная (Home View)**:
  - Приветственная панель с быстрыми шорткатами (альбомы и плейлисты из недавнего прослушивания).
  - Горизонтальные карусели («Heavy Rotation», «Made for You», «Featured»).
- **Поиск (Search View)**:
  - Живой поиск с дебаунсом.
  - Категоризация выдачи: Top Result (Лучшее совпадение), Songs, Artists, Albums, Playlists.
  - Быстрый переход в дискографию или профиль исполнителя.
- **Страница артиста (Artist View)**:
  - Большой динамический заголовок с баннером и количеством слушателей.
  - Топ-популярных песен с нумерацией и количеством прослушиваний.
  - Полная дискография с фильтрами: «Альбомы», «Синглы и EP», «Сборники».
- **Страница альбома / плейлиста (Album & Playlist Views)**:
  - Hero-секция с крупной обложкой, автором, датой релиза и длительностью.
  - Кнопка воспроизведения («Play All») и перемешивания («Shuffle»).
  - Список треков с указанием явного контента (Explicit), длительности и локального статуса.
- **Любимые треки (Saved Songs)**:
  - Быстрый доступ ко всей библиотеке понравившихся песен с сортировкой по дате добавления, исполнителю или названию.

## 6. Плееры: компактный бар и Immersive Player

### Компактный нижний бар (`PlayerBar.qml`)
- Миниатюрная обложка с индикатором воспроизведения.
- Название песни и кликабельные имена исполнителей.
- «Живой» волновой ползунок позиции трека.
- Быстрые кнопки: Like/Unlike, Shuffle, Previous, Play/Pause, Next, Repeat.
- Кнопки быстрого открытия: Очередь (`QueuePanel`), Тексты (`LyricsPanel`), Звуковой эквалайзер (`SoundPanel`), Полноэкранный режим.

### Полноэкранный Immersive Player (`ImmersivePlayer.qml`)
- Режим максимального погружения для фонового прослушивания или вечеринок.
- Огромная парящая обложка альбома с мягкой тенью и адаптивным свечением (`ArtworkGlow`).
- Жидкий анимированный фон (`LiquidBackdrop`), заполняющий весь экран.
- Выбор встроенных визуализаторов: спектральные полосы, пульсирующий ореол вокруг альбома, волновые линии.
- Интегрированная панель таймера сна (`SleepTimerPanel`).

## 7. Тексты песен (Synced Lyrics)

- **Синхронизация по времени**: Построчный скролл в реальном времени с подсветкой текущей активной строки.
- **Бэкенд текстов**: Получение синхронизированных текстов из Spotify Lyrics API и Musixmatch.
- **Интерактивность**: Клик по любой строке текста немедленно перематывает трек на соответствующую миллисекунду.
- **Плавная анимация**: Кинематографичный скролл текста с эффектом затухания по краям экрана (`edge_fade.frag`).

## 8. Локальные файлы и редактирование метаданных

- **Поддержка локальной библиотеки**:
  - Сканирование локальных папок с музыкой (MP3, FLAC, OGG, WAV, M4A).
  - Смешивание локальных файлов со Spotify-треками в общих плейлистах.
- **Встроенный редактор тегов (`LocalTrackEditor.qml`)**:
  - Редактирование ID3-тегов: Название трека, Исполнитель, Альбом, Год, Номер трека, Жанр.
  - Встраивание и замена обложки альбома (`CoverMaker`).

## 9. Служебные интеграции и ОС (Linux, Windows, macOS)

### Linux (Wayland & X11)
- **MPRIS v2**: Полный контроль через D-Bus интерфейс (`org.mpris.MediaPlayer2.swiftify`). Работают виджеты в GNOME Shell, KDE Plasma, Waybar, `playerctl`.
- **System Tray**: Иконка в системном трее со статусом воспроизведения и контекстным меню.
- **systemd-logind**: Автоматическая пауза при переходе ПК в спящий режим/гибернацию.
- **PipeWire / PulseAudio**: Отслеживание смены аудиовыходов на лету (наушники, динамики, внешние ЦАП).

### Windows
- **SystemMediaTransportControls (SMTC)**: Системный оверлей управления медиа Windows 10/11, поддержка медиа-клавиш клавиатуры и экрана блокировки.
- **Windows Taskbar**: Превью окна и кнопки управления на панели задач.

### macOS
- **Native Menu Bar**: Интеграция системного меню macOS (`MacMenuBar.qml`).
- **Now Playing**: Интеграция с центром управления macOS.

### Discord Rich Presence (RPC)
- Прямое локальное IPC-подключение к Discord без внешних тяжелых SDK.
- Отображение текущего трека, исполнителя, обложки и прошедшего времени с кнопкой «Слушать в Swiftify».

## 10. Статистика прослушиваний (Stats)

Встроенный аналог *stats.fm* и *Spicetify listening-stats*:
- **Источники данных**:
  - **Локальный трекер**: Сохраняет каждое прослушивание (>30 сек) в приватный файл `listening-history.jsonl`.
  - **stats.fm API**: Импорт публичной статистики аккаунта по имени пользователя.
- **Визуализация (`src/stats/`)**:
  - Топ треков, топ исполнителей, топ альбомов и жанров.
  - Фильтры по периодам: За сегодня, 4 недели, 6 месяцев, За все время.
  - Сортировка: по количеству прослушиваний или суммарному времени.
  - Интерактивный календарь активности (GitHub-like Heatmap матрица `CalendarHeatmap.qml`).
  - Экспорт истории в `.csv`.

## 11. Горячие клавиши и управление из командной строки

Swiftify использует архитектуру одного инстанса (`SingleInstance`). Повторный запуск передает аргументы активному окну:

| Аргумент CLI | Действие |
|---|---|
| `swiftify --play-pause` | Переключить паузу / воспроизведение |
| `swiftify --next` | Следующий трек |
| `swiftify --previous` | Предыдущий трек |
| `swiftify --immersive` | Открыть / закрыть полноэкранный Immersive плеер |
| `swiftify --stats` | Открыть экран статистики |

Поддерживается быстрая привязка к хоткеям в тайловых менеджерах (Hyprland, Sway, i3) и оконных средах (KDE, GNOME).

## 12. Таблица сравнения: Desktop vs Android

| Функция / Модуль | Swiftify Desktop (C++ / Qt 6) | Swiftify Android (Kotlin / Jetpack Compose) |
|---|---|---|
| **Ядро стриминга** | Rust `librespot` + C ABI | Rust `spotify-core` (spclient) + JNI / Media3 |
| **Fallback Soloist** | Есть (локальный демон + пайплайн) | Не требуется (мобильный spclient) |
| **Эквалайзер / DSP** | 10-полосный параметрический + Rubber Band | Системный Android AudioEffect / В разработке |
| **Pitch & Tempo** | Поддерживается (0.5x–2.0x, сдвиг полутонов) | Запланировано |
| **Synced Lyrics** | Есть (анимированный караоке-скролл) | Запланировано |
| **Визуализаторы** | Liquid Backdrop, Spectrum Bars/Halo (GLSL) | Упрощенный дизайн Material 3 |
| **Локальные файлы** | Полная поддержка + ID3 редактор | В разработке |
| **Интеграция с ОС** | MPRIS, Windows SMTC, Discord RPC, Tray | MediaSession, Notifications, Lockscreen |
| **Статистика** | Встроенный модуль Stats + stats.fm | Запланировано |
| **Очередь треков** | Продвинутая очередь с историей | Контекстная очередь (плейлисты/альбомы) |
